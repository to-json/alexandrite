# L1: Text & data core

The first wave of Go's standard library (decision S1). The packages are written in alexandrite, embedded in the compiler, and imported by Go's paths (`import "strings"`). The API shape is decision S2:

- Go's names in snake_case.
- `~T` where Go returns (T, error).
- `T?` where Go returns (T, bool).
- Tuples where Go returns two values.
- Every function whose first parameter takes a type is also a method on it: `s.has_prefix("x")`, `xs.index_func { it > 2 }`.

## The language, grown to fit

- **Tuples:**
  - `(A, B)` and `(A, B)?` types, `(a, b)` literals and `return a, b`;
  - `a, b = pair`, with `_` skipping an element, and `t[0]`;
  - element-wise coercion (`(1, "a")` as `(U8, Str)`).
- **Functions as values:**
  - a named function where a function is wanted (`sort_func(xs, by_len)`);
  - a block for a last parameter of function type, also through method sugar (`xs.index_func { it > 2 }`).
- **Parallel assignment to places:** `a[i], a[j] = a[j], a[i]`.
- **`panic(msg)`, `assert cond, "why"`, and Go's string escapes** (`\xHH \uHHHH \UHHHHHHHH \a \b \f \v \r`). Unknown escapes are errors.
- **Constants:**
  - folded Int constants stay exact until typed (`v: U64 = 1 << 63`);
  - an untyped constant in a ternary takes the other branch's type.
- **`Str#split` is Go's `strings.Split`:** empty fields are kept, and an empty separator splits into UTF-8 sequences.
- **`Unit` is a type name.**
- **Fixes:**
  - a function ending in an `if` whose branches all return (JIT verifier);
  - `Array#reverse` was miscompiled and is removed (`slices.reverse` reverses in place);
  - separate-compilation headers handle sized integers;
  - `alx fmt` keeps `~(A, B)<E>` tight.

## The std plumbing

- **Embedding:** `std/` is embedded by `compiler/build.rs`. A std package resolves when the module has no directory of that name.
- **Method sugar:** it applies after a type's own methods, and checks the receiver's outer shape for generic first parameters.
- **Tests:** the acceptance harness runs every package's tests on the JIT and in release builds.

## Tests

- Every std package's tests pass on the JIT and in release builds: 172 test blocks, plus thousands of generated assertions.
- New acceptance cases: `fmt`, `tuples`, `funcvalues` and `math`.
- Acceptance: **223 of 223 checks pass.**

## Not yet

- **Slices have no `==`** (as in Go); use `slices.equal`.
- **Top-level constants** are scalars or one string literal, so tables are encoded in strings.
- **No method sugar inside a package's own code or tests.**
- **`strconv.parse_float` is slow on inputs off its fast path:** microseconds to tens of microseconds each (no Eisel–Lemire yet).
- **Case mapping** in `strings` covers Latin, Greek and Cyrillic; `unicode.to_upper` covers everything, one rune at a time.
