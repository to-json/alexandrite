# L2: Systems core

The second wave of Go's standard library: files, streams, processes, clocks and command lines. It sits on a new C foreign-function interface, so the packages are alexandrite code over libc, as Go's are over `syscall`.

| Package | Functions | Tests | Notes |
|---|---|---|---|
| `os` | 70 | 12 | files, directories, links, stat, environment, process; `FsError` with messages like Go's (`open /x: no such file or directory`) |
| `io` | 38 | 9 | `Reader`, `Writer`, `Closer`, `Seeker` and their combinations; `copy`, `read_all`, `read_full`, `write_all`; EOF is `0` (F3) |
| `bufio` | 38 | 17 | buffered `Reader`/`Writer`; `Scanner` over lines, words, runes or bytes |
| `time` | 96 | 46 + ~1,700 assertions generated from Go | `Duration`, `Time`, Go's layouts for `format`/`parse`, monotonic `sub`; `sleep`, `after`, `tick`, `Timer`, `Ticker`; tested under five time zones |
| `flag` | 34 | 10 | Go's parsing rules; a `FlagSet` holds the values (there are no pointers); `-h` fails with the usage text |
| `path`, `path/filepath` | 24 | 11 | Go's `clean`, `join`, `split`, `match`, `rel`; `abs`, `glob`, `walk_dir` |

Built by four Sonnet agents in parallel worktrees, after the FFI (also an agent). An example, `acceptance/cases/wc.alx`, counts the words of its own source through `os` and `bufio`.

## The C FFI

```ruby
extern def write(fd: I32, buf: [Byte], n: Int) -> Int
extern def getenv(name: Str) -> Ptr
home = Str.from_cstr(getenv("HOME"))
fail "close: #{C.strerror(C.errno)}" if close(fd) < 0
```

- **Parameters:** sized integers, Float, Bool, `Ptr` (opaque), `Str` (a NUL-terminated copy made for the call) and `[Byte]` (a pointer to the first element).
- **Returns:** scalars, `Ptr` or nothing.
- **Strings back from C:** `Str.from_cstr` / `Str.from_ptr`.
- **errno:** `C.errno` is saved right after each call.
- **Purity:** calling C is I/O, so `fn` and `#[pure]` defs can't.
- **Per backend:**
  - C: a private name bound to the real symbol with `__asm__`, so it can't clash with system headers;
  - JIT: `dlsym`, with C's exact argument widths;
  - Rust oracle: `extern "C"` blocks;
  - browser: refuses.
- **Variadic functions** (`open`, `fcntl`) go through small runtime shims. `alx_sys_const("O_CREAT")` gives the platform's constants.

## Runtime additions

- **Sleeping parks the task:** `alx_sleep_ns` puts it on a timer list served by one timer thread, so its worker runs other tasks. 200 tasks sleeping 50 ms finish in 55 ms on one worker. Sleepers don't count as a deadlock.
- **Program arguments:** `alx run file.alx a b` (or `-- a b`) passes the arguments on, and native binaries read them from `main`.
- **Clocks** (wall, monotonic, local offset and zone) and **shims** for `stat`, directory reading and `environ`.

## The language and compiler, grown to fit

- **Fallible interface methods:**
  - `def read!(p: [Byte]) -> ~Int` in an interface, called as `r.~read!(p)`;
  - an implementor that can't fail satisfies one;
  - `~` on a direct `!` call propagates after the receiver is written back.
- **Interface calls in the region analysis** now use the implementors' summaries, instead of sending everything to the program region: 1.25 GB down to 213 MB on a 2-million-call loop.
- **Name resolution:**
  - a bare field read wins over a global function of the same name;
  - inside a struct, a method of `self` wins only when its arity fits.
- **`File` and `Time` are no longer reserved names.**

## Tests

- Every package's tests pass on the JIT and in release builds.
- New acceptance cases: `ffi` (plus 3 negative cases), `flags` and `wc`.
- Acceptance: **299 of 299 checks pass.**

## Not yet

- **Blocking I/O:** a read on a pipe, a tty or (later) a socket blocks its worker thread. The I/O event loop is L3.
- **Struct copies (solved for the std types, GO-VS-RUBY D36):** `bytes.Buffer`, `strings.Builder`, `bufio.Reader`/`Writer`/`Scanner`, `flag.FlagSet` and `os.File` keep their mutable state in a one-element slice, so copies share it: `io.copy(buf, file)` fills the caller's `buf`, and a `bufio.Reader` passed to a helper that reads a line leaves the caller continuing after it. Remaining caveat: a zero-value `Buffer.new` has no state until its first write, so copies taken before that don't share; use `bytes.new_buffer`. User-defined readers/writers with plain mutable fields still advance only in the copy.
- **Fixed after the first cut:**
  - a fallible call under `~` is now made in the region its result is placed in;
  - a `!` call reuses one receiver cell per call site, made empty at function entry (1M calls: 33 MB down to 2 MB peak);
  - a struct holding its own interface is a clear error suggesting a generic struct (`Lim[T] { inner: T }`, like Rust's `BufReader<R>`);
  - type-parameter bounds may name another package's interface (`[T: io.Reader]`);
  - the Rust oracle emits tuple structs for tuples wider than 12;
  - `loop` with no `break` is Never;
  - arrays have `join`.
- **Name resolution in tests:** importing `bytes` from a test of package `io` makes bytes' builtin `copy` resolve to `io.copy`, so the io-with-Buffer tests live in `std/os`.
- **Platform:** no time-zone database (UTC, Local and fixed zones only). Linux is untested.
