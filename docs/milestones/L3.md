# L3: Server core

The third wave, and the last milestone on the roadmap: what a Go-style network service needs. It comes in two layers:

- **Runtime:** an I/O event loop under the M:N scheduler (S4), so a socket read parks the task, not its thread.
- **Std packages in alexandrite:** `net`, `net/http`, `encoding/json` over compile-time derives (S3), `context` and `sync`.

```ruby
import "net/http"
import "encoding/json"

#[derive(Json)]
struct Greeting {
  to: Str
  #[json(omit_empty)] tags: [Str]
}

def hello(w: http.ResponseWriter, r: http.Request) -> Unit {
  g = Greeting.new(to: r.path_value("name") || "world", tags: [])
  w.header.set("Content-Type", "application/json")
  w.write_string!(g.to_json.unwrap)
}

mux = http.new_serve_mux
mux.handle_func("GET /hello/{name}", hello)
http.listen_and_serve(":8080", mux)
```

## The event loop

- **The poller:** one poller thread runs kqueue on macOS (epoll on Linux, untested).
- **`alx_fd_wait(fd, mode)`:** a task registers interest one-shot and parks. A plain thread (main) blocks in `poll(2)` instead.
- **Deadlock detection:** a task waiting on a socket counts like a sleeper, not as a deadlock.
- **Socket shims:** they make every descriptor non-blocking and close-on-exec. `net`'s reads, writes, accepts and connects wait on `EAGAIN` and retry.
- **Shared descriptors:** `Conn` and `Listener` hold their descriptor in an `Atomic[Int]`. Copies share it, and under R6 tasks may share a connection (one reads or accepts while another closes, as in Go). A close wakes the parked tasks, which then fail with `Closed`.

## Derives

`#[derive(Json)]` (details: `docs/notes/json-derive.md`) before a `struct` or `enum` is expanded by the parser into ordinary `def`s inside the type (`compiler/src/derive.rs`). Every backend therefore runs it unchanged, the browser included. The derived code is built on a small protocol (`json_enc`, `json_dec`, `json_zero`), which a hand-written type can implement instead. Unsupported field types fail at the derive with a message.

## Language and runtime fixes found on the way

- **Defers:** a function with a `defer` of a `!` call (one of two `defer`s) freed its frame region twice. The deferred code's own scope looked like leaving the function, so the frame was freed under a later frame that reused it. Found under ASan in `net/http`'s connection loop.
- **The Rust oracle's socket wait** now polls in slices: on macOS, closing a descriptor in another thread doesn't wake a `poll` on it.
- **A lambda's last call:** a lambda whose body is a single call returning Unit compiled to nothing. That broke every `->() { cancel(c) }`; it now runs.
- **Fallible calls under `~`:** a call under `~` is made in its placed region. A result returned through two fallible calls was freed with the frame.
- **Polling tasks yield:** `select ... else` lets the tasks queued on its worker run, adopting a task that hasn't started if need be. Before, a polling task starved them, because tasks are pinned to their worker.
- **Sharing checks:** an alias walk stops at values without shared storage, and the lock-escape check only counts outer variables the block writes. Both had been false positives.
- **Smaller fixes:**
  - blocks for a struct method's function parameter;
  - a discarded tuple in C;
  - `loop` with no `break` is Never;
  - `Array#join`;
  - a struct holding its own interface is a clear error (use a generic struct, like Rust's `BufReader<R>`);
  - bounds can name another package's interface;
  - Rust-oracle tuples wider than 12;
  - `!` calls reuse one receiver cell per call site (33 MB → 2 MB over 1M calls).

## Not yet

- **Memory per connection:** about 45 KB per parked connection task. Each task's regions touch whole 16 KB pages of their 1 MB chunks. A small first chunk per region would bring it toward Go's ~8 KB.
- **Preemption:** a task in a tight loop that never calls into the runtime starves the other tasks pinned to its worker. Polling `select` yields, but plain loops don't. Go preempts asynchronously.
- **Tasks stay on one worker** (R5): there's no work stealing and no migration.
- **Missing features:**
  - read/write deadlines and timeouts on connections;
  - UDP and Unix sockets;
  - TLS (crypto is a later wave);
  - HTTP/2;
  - `json` streaming (`Decoder` over a reader).
- **Platform:** `getaddrinfo` blocks its worker. Linux paths are untested. macOS caps the listen backlog at 128 (`kern.ipc.somaxconn`), so a burst of 10,000 connects pays SYN retries.
- **The agents:** three of this milestone's agents stalled (netpoll, json, http). I finished their work from checkpoints. The last `net/http` refactor checkpoint was dropped, and the merged version is the agent's last tested commit.
