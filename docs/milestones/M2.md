# M2: Everyday syntax

The constructs you reach for in every program, on all five backends. The test `acceptance/cases/syntax.alx` exercises all of them, and every backend prints the same 29 lines.

## What you can write now

```ruby
fn half(x: Int) -> Int { x / 2 }              # fn = a pure def
ƒ area(r: Float) -> Float { 3.14159 * r * r } # so is ƒ

def classify(n: Int) -> Str {
  case n {                                    # an expression
    0 => "zero"
    1 | 2 | 3 => "small"                      # alternatives
    4...10 => "medium"                        # ranges
    _ => "large"
  }
}

def sign(x: Float) -> Str {
  case {                                      # no subject: conditions (Go's switch true)
    x < 0 => "negative"
    x == 0 => "zero"
    _ => "positive"
  }
}

def grade(s: Int) -> Str {
  if s >= 90 { "A" } else if s >= 80 { "B" } else { "C" }   # if is an expression
}

for name, i in names.each_with_index {       # for loops, with destructuring
  puts "#{i}: #{name} (#{name.size} bytes)"   # interpolation
}

def countdown(n: Int) {
  defer puts "liftoff"                        # runs when the block exits
  ...
}
```

## What was built

- **`for x in xs { }`:** sugar over `each`, so it works on anything Enumerable (ranges, arrays, generators). `break`, `next` and `return` behave as in a Go `for range`. Several variables destructure tuples.
- **`case`:** with a subject, arms match values, ranges and alternatives (`|`); without one, each arm is a condition. A case with `_` is an expression whose arms must agree on a type. Without `_` nothing may match, so the case has no value.
- **`if` as an expression:** `x = if c { a } else { b }`, and a trailing `if`/`else` is the value of a function or block. `else if` joins `elsif`.
- **Interpolation:** `"#{expr}"` with any expression, nested quotes included; it uses `format`'s `%v`, so numbers print the Go way. `\#{` stays literal.
- **`defer`:** block-scoped, as decided. Deferred code runs in reverse order when its block exits by falling through, `return` (after the return value is computed), `break` or `next`, or an error propagating through `try`. A `defer` inside a loop body runs at the end of each iteration.
- **`fn` and `ƒ`:** a `def` that must be pure, checked like `#[pure]`.

Under the hood: `case` and value-`if` lower to conditionals over a statement sequence; `defer` lowers to cleanup code emitted at every exit, and the error paths of `try` now carry the cleanup each backend runs before propagating.
