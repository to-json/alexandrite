# S1: Go stdlib, wave 1

The first wave of the Go standard library port: small, self-contained packages that test the porting rules (docs/notes/porting-std.md) and the language, before the large ones (regexp, math/big, crypto, compress).

Each package keeps Go's import path under `std/`. It has Go's own tests translated, plus vectors generated from real Go. It passes `alx test` on the JIT and on release (C).

## Language changes

Each change was made on every backend (C, JIT, Rust oracle, wasm) and is tested in `acceptance/cases/stdport_fixes` (S1).

- **Qualified variant patterns:** `case e { csv.CsvError.FieldCount(..) => }`. The type part narrows which error variants match.
- **`(T)` groups a type:** for example `((A) -> B)?`, an optional function type.
- **Invalid UTF-8:** decodes to U+FFFD one byte at a time, as in Go (`"\x80A".runes` is `[65533, 65]`).
- **Element-wise literal coercion:** array literals coerce element by element (`Str.from_bytes([128, 65])`, `[Iface]` literals mixing implementors).
- **`==` on optionals:** both `T? == T?` and `T? == T`.
- **Integer precision in `format`:** `%.3d` and `%.4x` behave as in Go: the 0 flag is ignored, and `%.0d` of 0 prints nothing.
- **`opt?.field || none`:** keeps the optional type.
- **Keywords as field names:** a keyword can name a struct field or a named argument (`next: T`, `N.new(next: x)`), as Go's `next` fields need.
- **Static methods on generic types:** `def self.make(v: T) -> R[T]` can be called as `R.make(v)`, or as `R[Byte].make(7)` to give the type explicitly.
- **Type parameters from the wanted result:** when the arguments don't decide a parameter, the wanted type does (`x: R[Int] = R.empty`, `ns: [Str] = none_of(2)`).
- **Covariant interface results:** a method returning `Digest` satisfies an interface's `def clone -> Hash` when Digest is a Hash.
- **Self-containing closures are diagnosed:** a closure that captures a value holding its own type is reported as an error. It used to overflow the compiler's stack.

## Compiler fixes

- **JIT stack slots:** slots are reused per statement. Deep call chains in big test blocks used to overflow the task stack.
- **Type-name shadowing:** inside a package, a type name resolves to the package's own type before the main file's.
- **C declarations:** the C backend declares array types that appear only in literals.

The issue log is docs/notes/port-issues.md. One item is still partly open there: lambda allocation placement (#5).
